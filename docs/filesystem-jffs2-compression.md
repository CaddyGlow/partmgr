# Explicit immutable JFFS2 RTIME and ZLIB profile

`Jffs2Volume::open_compressed` accepts NONE, ZERO, RTIME and ZLIB regular-file nodes under separately supplied `Jffs2CompressionLimits`. `open` and strict owned editing retain the NONE/ZERO profile. The borrowed decoder shares validated codec primitives with the explicit opt-in editing continuation described in [compressed editing](filesystem-jffs2-edit-compression.md). Immutable compression support alone grants no mutation authority. Rubin, dynamic Rubin, COPY and LZO remain requested later scope; RTIME/ZLIB offline authoring has a separate [builder profile](filesystem-jffs2-builder-compression.md). Unsupported active codecs or extensions return errors, never a partially certified inventory.

The primary references are Linux [native node definitions](https://raw.githubusercontent.com/torvalds/linux/master/include/uapi/linux/jffs2.h), [RTIME decoder](https://raw.githubusercontent.com/torvalds/linux/master/fs/jffs2/compr_rtime.c), [ZLIB decoder](https://raw.githubusercontent.com/torvalds/linux/master/fs/jffs2/compr_zlib.c), and [version reconstruction](https://raw.githubusercontent.com/torvalds/linux/master/fs/jffs2/readinode.c). Codec numbers are native RTIME 2 and ZLIB 6; encoded data CRC covers compressed bytes. RTIME reconstructs literal/run pairs using the native 256-entry unsigned-16-bit occurrence table and overlapping backreferences. This reader additionally rejects truncated pairs, invalid references, output overflow and unused trailing input. ZLIB requires RFC1950 framing, exact stream termination, exact consumed/produced lengths and a valid Adler checksum. Linux may skip Adler verification after recognizing a valid wrapper; this deliberately stricter profile requires it. Raw DEFLATE, dictionaries and damaged streams are unsupported.

Every accurate compressed node, including superseded and unreachable history, passes header/node/data CRCs and bounded decompression during opening. Output is discarded immediately. Thus malformed compressed history prevents successful opening and cannot produce a prematurely complete audit or free-range report. Explicitly obsolete nodes retain the existing normalized-header-only certification boundary. Namespace audit and informational whole-erased-block reporting retain their previous contracts and provide no erase authority.

Reconstruction uses the same highest-version `isize`, overlay offsets, exact names, hardlink identities and explicit hole semantics as the strict profile. Compression descriptors are retained beside metadata; private tagged locators distinguish encoded node-relative bytes from ordinary physical data. They are never exposed as physical allocation claims. Symlink histories still require complete uncompressed nodes; directories cannot carry compressed data. The original caller-guaranteed-stable source and its cancellation context remain retained.

Compressed data nodes require positive encoded and logical lengths; empty metadata records remain NONE. Per-node encoded and decoded limits are each at most 65536 bytes. Complete-scan encoded and decoded totals, scan/index/fragment limits and encoded-plus-decoded byte-work are independently bounded. Each deferred read checks a cumulative codec-work cap. There is no retained decoded cache: random reads decode only the referenced bounded node into an exact output buffer, then copy the requested fragment. They do not extract the whole logical file. A node referenced by separate fragments may be decoded again; this costs bounded work rather than retaining payload-sized cache memory.

Shared resources reserve descriptor inventory, encoded and exact decoded buffers, and an additional 131072 bytes of conservative decoder workspace. The published `flate2` 1.1.10 dependency uses only `rust_backend`; its low-level `Decompress` API receives caller-sized output, with no convenience decoder that grows output. Buffer leases remain alive through copying and refund after each read. Caller and retained-source cancellation, backing length and causal I/O failures are preserved. Concurrent cloned handles share immutable inventory while each operation charges its own supplied resources.

Portable tests independently encode RTIME and stored RFC1950 streams in both byte orders, then overlay a newer NONE fragment and retain a zero tail. Whole and random ranges, malformed compressed input with recomputed native CRCs, Adler/trailing/length defects, expansion/total/work caps, low memory, causal reads and refunds are exercised. A separate owned-storage test proves the strict default rejects both codecs before editor writes. These tests retain native byte names and hardlink histories from the independent fixture.

The ignored native test must be explicitly enabled with a fresh `JFFS2_CODEC_EVIDENCE` directory, `JFFS2_TOOLS` mtd-utils directory and `JFFS2_EXTRACTOR` Jefferson executable; missing tools fail. It forces each compressor separately with `mkfs.jffs2`, in both byte orders, verifies that at least 20 actual compressed payload nodes exist, validates completed CRCs with `jffs2dump`, compares complete 98304-byte payload and random ranges through a deferred common tree stream, then compares independent Jefferson extraction of the exact raw image. Commands, limits, versions, hashes, baked/live source equality and end-of-run source/tool/binary revalidation are retained. This establishes completed native compressed payload reading, not mounted recovery or physical NOR behavior.
