# Native optical TreeSource

`partmgr_optical::tree::OpticalTreeSource::new(index, resources)` adapts the complete selected namespace in `OpticalReadIndex` to the common immutable `TreeSource` contract. It uses the published crates.io **libmkiso 0.1.4** topology and classified-extent APIs. The standalone integration keeps its optical dependency outside the root crate. Development tests override only the unpublished partmgr filesystem API; no libmkiso sibling checkout or dependency override is used.

Native parent indices determine directory relationships. Display paths are never split or reconstructed into names. ISO uses its actual selected semantic leaf: Primary identifier bytes, Joliet UTF-16 units, or Rock Ridge NM bytes with the upstream primary fallback. Stored identifiers, including version suffixes when present, remain available separately. The adapter does not invent a version suffix when the selected namespace did not store one, strip suffixes, or assume that preferred namespaces selected Rock Ridge. ISO root identity is source-scoped and synthetic. ISO indexed-record identities do not claim recognition of Rock Ridge hard links across records or namespaces.

UDF ordinary names decode their exact OSTA compression-eight or compression-sixteen units into the common UTF-16 name type, while retaining the original compressed bytes in the native inspection. Root identity uses the prevailing root partition/ICB key. Hard-linked file occurrences keep the same identity, generation, payload map and native object metadata; inconsistent aliases fail closed. Directory aliases, cycles, missing or nondirectory parents and duplicate exact leaf names are rejected. Parent-chain work is bounded by the original selected depth/entry limits.

Named, root and system streams stay separate from directory pages. Their declared native owner occurrence resolves to the owner's source-scoped identity, including shared identities for hard links. Named and system names remain distinct stream categories. Stream lists expose logical lengths; opening one verifies ownership and returns a file handle whose common identity is its **owner**, while the native inspection retains the stream's own ICB identity. Duplicate associations must have consistent identities, maps and metadata. Unowned or ambiguous streams fail closed. The parser is dropped after checked map/metadata copies; no unsafe `Send`/`Sync` implementation wraps its single-threaded bookkeeping.

Recorded UDF extents become `Data`, unallocated extents become `Hole`, and allocated-unrecorded extents become `Unwritten`. Both zero classes produce logical zeros without reading their payload backing. The common extent visitor now exposes the exact classifications using `visit_classified_extents`, preserving their distinction. ISO multi-section files retain their validated recorded maps. Symbolic links are inventoried without following them and have no ordinary data handle. Rock Ridge device/special modes remain visible as `Special`; contradictory type metadata fails closed. Unsupported UDF special-file types are rejected by the published parser rather than silently omitted.

Common metadata preserves absence and lack of inspection explicitly. Native permission values remain `Known` under their source profile: Rock Ridge values have POSIX mode semantics, while **UDF permission bits, such as 0x14a5, are not POSIX mode bits** and are not converted to them. Ownership is the native UID/GID pair encoded as two little-endian u32 values. Exact stored names, timestamps and extension bytes remain source-scoped attributes or opaque fields. No guessed epoch/clock conversion creates common timestamps; created/modified/accessed fields remain uninspectable when conversion or individual-field inspection is unavailable. Exact timestamp encodings and precision are retained in opaque attributes. Security and reparse semantics that the published reader does not classify remain uninspectable.

`optical.inspection-state` retains six upstream field-status bytes in native-name, timestamps, ownership, permissions, extensions and opaque order: zero means Absent, one Uninspected, two Present and three NotWritable. This keeps input inspection/writability distinctions reviewable even when the common metadata field lacks a NotWritable variant. Opaque bytes carry no transplantation guarantee. A symbolic link's decoded logical target is available as an attribute; its exact encoded native representation remains explicitly uninspectable through the common metadata contract. `inspection()` borrows the retained complete reader index, including source-native metadata of owned streams that the common object-metadata API does not expose separately.

Construction reserves a conservative additional topology envelope before allocations. The reader's existing inventory/map lease remains alive until its last deferred file handle drops. Returned directory pages, metadata values, stream lists and owner-identity wrappers reserve their own retained storage through the caller's shared pool. Pages use an opaque token scoped to this tree instance and directory; wrong-directory, foreign-tree, malformed and out-of-range tokens fail. Operations check cancellation, source-scoped identity/generation and retained-source length. Stability is truthfully `CallerGuaranteedStable`: source length detection and open handles do not create an immutable snapshot or exclude transient external writes.

Three focused ordinary tests cover Primary/Joliet/Rock Ridge/preferred selection, deep native parents, native-vs-stored leaf differences, exact Primary version retention, scoped paging, stale identities, root metadata, Japanese UDF names, hard links, sparse/unwritten extents, named/root/system stream ownership and owner identities, links, budget exhaustion, cancellation and leases surviving tree removal. A FAT copy preflight test rejects owned-stream loss explicitly. This does not silently convert a multi-stream object into an ordinary single-stream file.

The separate explicitly enabled native test covers direct optical-to-FAT authoring:

```sh
PARTMGR_OPTICAL_TREE_EVIDENCE=/data/cache/new-optical-tree-run \
  cargo test --manifest-path integration/optical/Cargo.toml --locked \
  --config 'patch.crates-io.partmgr.path="/path/to/partmgr"' \
  --test tree native_iso_and_udf_to_fat_without_capture_host_extraction \
  -- --ignored
```

It requires a fresh evidence directory, dosfstools, mtools and sha256sum. It reads actual nested Rock Ridge ISO and UDF images through `OpticalTreeSource`, preflights content-only deterministic metadata transformations, emits fresh FAT16 images from deferred optical file streams, and reopens a complete FAT ownership/state audit. It then uses independent `fsck.fat -n -v` and `mcopy` to validate the nested 131,089-byte file and an empty file. Validation extraction occurs after capture; the capture does not extract a host directory tree. Exact source/destination byte comparisons require native validators to leave images unchanged. The receipt records tool versions, implementation/test-binary hashes, native command arguments/logs, image/payload hashes and distinct reopened-audit/native-validation statuses.

Verified receipt: `/data/cache/partmgr-optical-tree-registry-v014-20261007/receipt.txt` passed both ISO and UDF routes using published libmkiso 0.1.4, dosfstools 4.2 and mtools 4.0.49. Each route emitted two files, verified the complete 33,554,432-byte FAT16 image, passed reopened allocation/state audit and native fsck, and recovered the exact expected large and empty payloads without source/destination mutation. Full metadata-preserving capture, unsupported optical profiles, ISO hard-link recognition, stream metadata emission and firmware boot correctness remain separate work. This adapter supplies faithful selected native topology and deferred content; it does not claim a complete metadata-preserving destination implementation.
